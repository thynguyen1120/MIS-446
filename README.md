# MIS-446 | Power BI Project

A Power BI course project containing an interactive report and its embedded data model. The available report includes revenue visualizations, including total revenue and revenue by country.

## Open the report

1. Open [MIS-446_recovered.pbix](MIS-446_recovered.pbix) and select **Download raw file** on GitHub.
2. Open the downloaded file in Power BI Desktop on a Windows computer.
3. Explore the report pages and embedded data model.

GitHub stores the PBIX file but does not render its interactive report. On a Mac, use Power BI Service in a browser to access a published report.

## Recovery status

This file was exported from the Power BI Service report **446 cleaned data (1)** on September 29, 2026, using the option to download both the report and its data. The exported file contains the report layout and an embedded DataModel.

The recovered report is a draft with two pages, **Page 1** and **Page 2**; some visuals remain unfinished. It has not been verified as a complete copy of the original project.

Original standalone source files (such as CSV or Excel files) are not included in this repository. Refreshing the report may require reconnecting to the original data sources.
